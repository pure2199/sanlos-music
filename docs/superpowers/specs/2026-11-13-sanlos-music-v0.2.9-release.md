### 3.2 发布说明里**必须出现**的数字（全部来自可复现实测）

| 数字 | 值 | 出处 |
|---|---|---|
| 写盘节流 | **每 10 秒**写一次（切歌 / 暂停时也写）⇒ 恢复点误差 **≤ 10 秒** | `src/state/playerStore.ts`（`RESUME_SAVE_INTERVAL_MS = 10_000`） |
| 恢复门槛 | 位置 **≥ 30 秒** **且** 距结尾 **≥ 15 秒** | `src/player/resume.ts`（`RESUME_MIN_POSITION_SEC` / `RESUME_TAIL_GUARD_SEC`） |
| 偏好白名单 | **11 → 12 个键**（新增 `autoplay`，**只认布尔**） | `electron/ipc.ts`（`sanitizePatch`） |
| 「不恢复」的原因 | **6 种**：`disabled` / `no-record` / `not-worth` / `song-gone` / `lookup-failed` / `superseded` | `src/state/resumeFlow.ts` |
| 自动化 | `tsc --noEmit` **0 error**；`vitest` **118 files / 2431 passed / 0 failed**（基线 117 / 2393 ⇒ 净增 1 file / 38 条）；`npm run build` 成功 | 本轮**实测**（同 HEAD 的源码，与 T89-⑲ 那一轮一致） |
| **真机实证** | 第一次播到 **47.9s**（《茨厂街（粤语谐剧·黄庆全 陈自成 吴金英）》）⇒ 退出 ⇒ 重开 ⇒ **同一首**、进度 **50.5s**（不是 0） | `release/verify/t89-19-resume-real.json`（连**真实 NAS** 的探针） |
| 新增单测 | `test/resume-playback.test.ts` **38 条** | T89-⑲ 实现轮 |

⚠️ **真机实证那一条必须写成「恢复点是最后一次写盘的位置」** ⇒ 不许写成「精确回到 47.9s」。

### 3.3 ⚠️ 四条**如实标注**（不许粉饰）

1. **启动时会自动出声** —— 「启动时自动播放」**默认开启** ⇒ 不喜欢请到 **设置 → 通用** 关掉。
2. **恢复点有误差** —— 记录**每 10 秒**写一次 ⇒ 恢复的是**最后一次写盘**的位置，误差 **≤ 10 秒**
   （异常退出最多丢 10 秒）。
3. **「上次那首已不在曲库」时不做恢复** —— 曲库里查不到完整曲目就**如实不恢复**，
   **不拿残缺数据硬播**（否则可能播不起来，或把服务端收藏状态反过来写掉）。
4. **回滚到 v0.2.8 会丢掉「关闭自动播放」这个开关的取值** —— 老版本的偏好白名单**不认识** `autoplay`
   ⇒ 读的时候**静默丢弃**（不崩、不伤别的键）⇒ 回滚后再升回来，开关回到**默认开启**。
