# T101 规格：「有声」页改成**专辑页同款**（封面卡片网格）+ 修**播放模块**

> 起因：用户 2026-11-17 的两句（原话）——
> ① 「**不能做成专辑页那样吗**」；
> ② 「**有声页的播放模块 UI 有问题**」。
>
> ⇒ 口径钉死：**有声页的形态 = 专辑页的形态**（封面卡片网格）；
> ⇒ **播放模块**三处修：详情页加「播放全书」/ 全屏页歌词不卡 / 有声默认落「队列」。

## 六、待校准 / 遗留

- ⚠ **封面 id 的两条路可能不是同一张图**（扫描路径 = 该组**第一首曲目**的 `coverId`；秒搜路径 = **专辑自己的** `coverId`）
  ⇒ ⚠ **真机实测：服务端「专辑的 `coverId`」本身也是 `track_` 形态** ⇒ 「专辑页 `album_xxx` / 有声页 `track_xxx`」**只对 E2E mock 成立**；
  ⇒ ⚠ **真机实测两条路给出的是两个不同的封面 id** ⇒ 同一张卡片在两处**可能显示不同的图** ⇒ **待拍板**（见「九、真机复验结果」）；
  但**逐首不同封面**的专辑会取到第一首的封面（**已知取舍**，**实机已见到**：同一张专辑里不同首曲目的封面确实不同）；
- ⚠ **旧落盘没有封面** ⇒ 进页时按需补拉 `/album/detail`（每张 1 个请求）⇒ **补完回写落盘** ⇒ 只补一次；
- ⚠ **「播放全书」只在有声详情页出现**（普通专辑详情页**不动** ⇒ 既有行为一字不变）；
- ⚠ 歌词超时阈值取 **12 秒**（实测外部源一轮失败约 10–30 秒 ⇒ 取中间值）；
- ⚠ **14 集掉队**（《极品家丁》`bracket` 抢走中段集号）**不在本轮** ⇒ 仍是 T101 之后的候选；

- ⚠ 数字**只代表那台机那个账号**。

### 三、⚠ 真机实测出来的**口径修正**（本规格 §六 第 1 条**作废**）

1. ⚠ **服务端「专辑的 `coverId`」本身就是 `track_` 形态**（实测 `track_66f7a2fc…` / `track_23e5f5f2…`）
   ⇒ 「专辑页用 `album_xxx`、有声页用 `track_xxx`」这个说法**只对 E2E mock 成立**，**真实服务端不是这样**
   ⇒ 凡按 `album_` / `track_` 区分两条路的说法**按本条更正**；
2. ⚠ **扫描路径与秒搜路径的封面 id 不是同一个**（实测《让青春继续第一季》）：
   - 扫描路径（主列表卡片）= `track_118fe863…` ⇒ **该组代表专辑第一首曲目**的封面；
   - 秒搜路径（秒搜卡片）= `track_66f7a2fc…` ⇒ **专辑自己的** `coverId`；

   ⇒ **同一张卡片在「主列表」与「秒搜结果」里可能显示不同的图** ⇒ **待拍板**
   （统一取专辑封面 ⇔ 扫描路径要多 1 个 `/album/detail`；统一取曲目封面 ⇔ 秒搜路径要多 1 个请求）；
3. ⚠ **「逐首不同封面 ⇒ 取第一首」这个取舍，实机见到了**：同一张专辑（guid `09a37310…`）里
   「扫描顺序第一首」= `track_118fe863…`、另一顺序取到的「第一首」= `track_b9a2187d…` ⇒ **两张不同的图**；
   （另一张 1 集专辑 `5f548503…` 的专辑封面与首曲封面**恰好相同** `track_23e5f5f2…` ⇒ **逐张不一定不同**）；
4. ⚠ 「让青春继续第三季」**整部都没有封面 id** ⇒ 卡片画占位块（**如实**如此）；
5. ⚠ 秒搜 **312** 条里 **45** 条没有封面 id ⇒ 同样是占位块；秒搜卡片的**来源小字为空**
   （来源只在**扫描**来的卡片上有）；
6. ⚠ 秒搜命中集**仍不稳定**（312 条 = 服务端子串 + top-N）⇒ 混着《青春的喝彩》《继续》等**不同名**作品
   ⇒ 「只显示名字全等的 / 名字全等置顶」⇒ **待拍板**（沿用 T100 的遗留）；
7. ⚠ **14 集掉队**（《极品家丁》）与「第 1.2 集」季.集标签 ⇒ 沿用 T100 的遗留，**未动**。

### 四、⚠ 探针自己踩的坑（已修，记下来）

⚠ **第一轮把详情页读早了**：等「已加载 N / N」的判据写成 `n(m[1]) >= n(m[2])`
⇒ 加载**前**的状态行就是「已加载 **0** / 0，加载中…」⇒ **0 >= 0 立刻成立** ⇒ 读到的是
「正在按集序整理…」+ 0 行 + 没有「播放全书」按钮。
⇒ 正解：**要求 `n(m[1]) > 0`**，并**另外等「播放全书」按钮真的在**（它只在曲目加载完之后才渲染）⇒ 重跑即真。
⚠ 这是「**等终态**」纪律的又一例：**「看起来满足条件」的终态也可能是假终态**。

⚠ 探针的 `app.close()` **不返回**（残留 5 个 electron 进程）⇒ 结果已落盘后按 `ExecutablePath`
前缀筛 `workspace\node_modules\electron\dist` 再 `Stop-Process` 清理（**用户装的 v0.2.9 未在运行、未被碰**）。
