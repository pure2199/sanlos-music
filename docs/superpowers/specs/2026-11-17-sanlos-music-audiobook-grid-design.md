# T101 规格：「有声」页改成**专辑页同款**（封面卡片网格）+ 修**播放模块**

> 起因：用户 2026-11-17 的两句（原话）——
> ① 「**不能做成专辑页那样吗**」；
> ② 「**有声页的播放模块 UI 有问题**」。
>
> ⇒ 口径钉死：**有声页的形态 = 专辑页的形态**（封面卡片网格）；
> ⇒ **播放模块**三处修：详情页加「播放全书」/ 全屏页歌词不卡 / 有声默认落「队列」。

---

## 一、现状（**代码事实 + 真机截图**）

| 位置 | 现状 | 证据 |
|---|---|---|
| 专辑页 | **封面卡片网格**（`.fnm-card` + `CoverImage` + 标题 + 歌手名） | 截图 `shots/1-albums.png` |
| 有声页 | **纯文字长列表**（`<ul>` + 每条 4 行文字：标题 / 来源 / 集数 / **结构信号长句** / 「不是有声」按钮） | 截图 `shots/3-audiobooks.png` |
| 有声**详情页** | **没有「播放全书」入口**（只能双击行）；顶部那条是「Ctrl/Shift 多选后可批量下载」的**下载**提示 | 截图 `shots/5-audiobook-detail.png` |
| 有声**全屏播放页** | 默认落在「歌词」标签，而**有声没有歌词** ⇒ **6 秒后仍卡「正在加载歌词…」**，整页一大片空白 | 截图 `shots/13-audiobook-fullplayer.png`；DOM 实测 `panelText` 含「正在加载歌词…」 |

⚠ **封面是缺的那一块**：扫描路径的命中条目（`AudiobookHit`）**没有 `coverId`** ⇒ 卡片画不出封面；
秒搜路径**本来就有**（`/search/album` → `mapAlbum` → `coverId`）。

## 二、用户拍板的口径（2026-11-17）

| # | 口径 | 说明 |
|---|---|---|
| P1 | **形态跟专辑页一样** | 封面 + 标题 + 副标题；卡片只管下钻 |
| P2 | **卡片要有封面** | 扫描路径也要有 ⇒ 封面要**顺手记下来**（不要额外请求） |
| P3 | **结构信号不占列表** | 那行长句挪到**详情页**（信息不丢） |
| P4 | **「不是有声」挪到详情页** | 详情页已有「这不是有声」⇒ 卡片不再挂按钮 |
| P5 | **播放模块三处都修** | ① 详情页「播放全书」② 全屏页歌词超时兜底 ③ 有声默认落「队列」 |

## 四、验收点

1. **有声页第一屏 = 封面卡片网格**（`.fnm-card` 结构，同专辑页）⇒ 9 部作品 = 9 张卡片，**有封面**；
2. 卡片副标题 = 「32 集 · 单集均长 14 分 · **合并了 2 张专辑**」；来源小字 = 「在「有声小说」目录下」；
3. **秒搜结果也是卡片**（同一套样式），且**立刻有封面**（`/search/album` 自带 `coverId`）；
4. **结构信号在详情页仍可见**（信息没丢，只是换了位置）；
5. 详情页「**播放全书**」⇒ 播放条起播第 1 集、**队列 = 整本 32 集**；
6. 有声的全屏播放页**不再**卡「正在加载歌词…」⇒ 默认落「**队列**」；
7. **音乐歌的行为一字不变**（既有歌词 / 队列 / 播放条测试全绿）；
8. `tsc --noEmit` 0 error；Vitest 全绿；Playwright 全绿；**变异自证 ≥ 4 条全红 ⇒ 还原回绿**；
9. **真机复验**（真实 NAS + 真实账号）：有声页 9 张卡片**有封面**、秒搜卡片有封面、「播放全书」可用、全屏页不卡歌词。

## 六、待校准 / 遗留

- ⚠ **扫描路径记的是「曲目封面」**（`track_xxx`），专辑页用的是「专辑封面」（`album_xxx`）
  ⇒ 实测有声专辑两者**指向同一张图**（真机复验确认）⇒ 观感一致；
  但**逐首不同封面**的专辑会取到第一首的封面（**已知取舍**，未实测遇到）；
- ⚠ **旧落盘没有封面** ⇒ 进页时按需补拉 `/album/detail`（每张 1 个请求）⇒ **补完回写落盘** ⇒ 只补一次；
- ⚠ **「播放全书」只在有声详情页出现**（普通专辑详情页**不动** ⇒ 既有行为一字不变）；
- ⚠ 歌词超时阈值取 **12 秒**（实测外部源一轮失败约 10–30 秒 ⇒ 取中间值）；
- ⚠ **14 集掉队**（《极品家丁》`bracket` 抢走中段集号）**不在本轮** ⇒ 仍是 T101 之后的候选；
- ⚠ 「第 1.2 集」季.集标签口径**不在本轮**；
- ⚠ 数字**只代表那台机那个账号**。
