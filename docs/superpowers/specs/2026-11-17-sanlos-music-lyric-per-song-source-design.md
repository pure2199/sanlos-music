# T107 规格：**按歌选源**（歌词匹配不准 ⇒ 手动指定这首歌用哪个源）

> 状态：**规格先行**（实现前定稿）。
> 起草：2026-11-17。
> 起因：用户 2026-11-17 的第二句话 ——
> 「有歌词匹配不准确的，**应该可以手动选择歌词**」。
> 交互形态：用户 2026-11-17 拍板 ⇒ **按歌选源**（备选的「候选里挑」「手贴歌词」本轮不做）。

---

## 一、这一轮要解决什么（一句话）

**某首歌自动匹配到的歌词不准（同名歌别的版本 / 源里的词是错的）**
⇒ 用户能对**这一首歌**指定「用哪个源取词」，并能一键**恢复自动**。

---

## 三、方案

### ① 语义（三条，用户 2026-11-17 已认可）

1. **「指定源」= 排到源链第一位，其余源仍兜底**。
   选「酷狗」⇒ 链 = `酷狗 → 网易云 → lrclib → QQ → 酷我 → 咪咕 → 自定义`。
   ⚠ 酷狗没这首歌时**仍会落到别的源** ⇒ 界面**如实显示实际命中的那个源**（沿用 T73 既有口径，不装作是用户选的那个）。
2. **「恢复自动」** ⇒ 清掉这首歌的指定 ⇒ 回到全局源链（设置里的默认源）。
3. **只对这一首歌生效**（按曲库 guid 索引）⇒ 换歌就失效；
   **有声读物**（有声小说）本来就没歌词 ⇒ **不显示换源控件**（不给无用控件）。

### ② 数据流（五步）

1. 全屏播放页「歌词」标签页底部，在既有「歌词来源：X」那行下面加一排**源按钮**
   （网易云 / lrclib / QQ / 酷狗 / 酷我 / 咪咕 / 自定义 ＋「恢复自动」）。
2. 点一下 ⇒ 写入渲染层 `localStorage`（zustand store，**上限 200 条，超出淘汰最旧**）⇒ **乐观应用**，写失败**回滚**并给出提示。
3. 全屏页取词的 effect **依赖该指定** ⇒ 立刻重取。
4. IPC `lyric:fetch` 增一个**可选** `source` 字段 ⇒ 主进程过白名单
   （`normalizeLyricSource`，非法值**丢弃** ⇒ 退回全局源）⇒ `buildSourceChain(指定源, 模板)`。
5. **桌面歌词 / 词岛**取词也发生在**主窗口渲染层**（`lyricOverlay.ts`）⇒ 订阅指定变化 ⇒
   `publishTrack(true)` **重取重推** ⇒ **桌面歌词自动跟随**，不用单独改窗。

### ③ 安全边界（**不放宽**的那几条照旧）

- ✅ 渲染层**仍然不能传 URL / 模板** ⇒ 模板永远取**主进程偏好**（用户自己配的）⇒ 主进程**不会**变成任意出网代理；
- ✅ 渲染层只能指定**白名单内的源名**（`LYRIC_SOURCES`）⇒ 非法值一律丢弃；
- ✅ 抓取**全在主进程**，走**干净的 Chromium 分区栈**，**不附带 NAS 的 token / Cookie**；
- ⚠️ **唯一放宽的一条**：渲染层可以指定「用哪个**源**」（不是「抓哪个**地址**」）——
  这些源本来就在链里 ⇒ 不构成提权。**注释要写明这条边界的变化**（`shared/playerBridge.ts` / `electron/ipc.ts`）。

### ④ 存储（为什么住 `localStorage` 而不是 `prefs.json`）

| 理由 | 说明 |
|---|---|
| 语义 | 「这首歌用哪个源」是**运行状态**（跟曲库走），不是「用户偏好」 |
| 纪律一致 | 仓库既有先例：「上次播到哪」明确**不进 `prefs.json`**（`src/player/resume.ts` 顶部） |
| 单一真相源 | 取词与界面**都在渲染层** ⇒ 同一个 store ⇒ **不需要镜像/同步** |
| 容量 | 200 条 × ~60 B ≈ 12 KB ≪ `localStorage` 约 5 MB 配额 |

⚠ **上限 200 条**：超出时按写入时间**淘汰最旧的**（防止无限涨）。
⚠ **写不进去（配额满 / 隐私模式）** ⇒ **静默降级**为「只在本次运行内有效」，**不崩、不假装成功**（沿用 `resumeBridge.ts` 的纪律）。

## 五、验收点

1. 全屏页点「酷狗音乐」⇒ **歌词内容换成酷狗那份**（状态行如实显示实际命中的源）；
2. **桌面歌词 / 词岛跟着换**（不换歌、不切窗口）；
3. 「恢复自动」⇒ 回到全局源链；
4. 换歌 ⇒ 指定**不跟着走**（只对这一首歌生效）；
5. 有声读物 ⇒ **不出现**换源控件；
6. 非法源名（渲染层乱传）⇒ 主进程**丢弃** ⇒ 用全局源（**不是**出网代理）；
7. **既有测试一条不许删、断言一条不许弱化**；
8. 变异自证：把「指定源生效」改坏 ⇒ 对应测试**必须变红**（证明咬得住）。

## 六、待校准 / 遗留

- ⚠ **桌面歌词窗内不能换源**（v1 不做，它只接收渲染层推送的歌词）⇒ 但它会**跟随**主窗口的指定；
- ⚠ 指定按**曲库 guid** 生效 ⇒ 换账号 / 换曲库不通用（用户数据归用户自己）；
- ⚠ 「指定源排在链首、其余仍兜底」是本轮口径 ⇒ 若用户想要「**只查这一个源，查不到就是没有**」，
  改动只在 `buildSourceChain` 一处（可另开小任务）；
- ⚠ 「候选里挑」「手贴歌词」两种形态本轮**不做**；
- ⚠ 本轮**没有真机复验**（真实 NAS ＋ 真实账号）⇒ 界面效果**待用户在真机上确认**；
- ⚠ 真机实测数字一律**不写死**。
