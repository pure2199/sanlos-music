# T102 规格：把「有声」页的封面 id **统一**（同一张卡片，两处显示同一张图）

> 起因：用户 2026-11-17 在 T101 收尾时拍板的下一件事 ——
> 「**统一封面 id**」。
> ⇒ 口径钉死：「有声」页上**同一张卡片**，在「主列表」与「秒搜结果」里显示**同一个封面 id**；
> 且与**专辑页**显示同一张专辑时的封面**一致**。

---

## 一、现状（**真机实测**，2026-11-17）

| 位置 | 封面来源 | 实测 id（《让青春继续第一季》） |
|---|---|---|
| 有声页「**主列表**」（扫描路径） | 扫描时记下的**该组第一首曲目**的 `coverId` | `track_118fe863…` |
| 有声页「**秒搜结果**」（搜索路径） | `/search/album` **自带**的**专辑** `coverId` | `track_66f7a2fc…` |
| 专辑页（同一张专辑） | `/album/list` 的**专辑** `coverId` | `track_66f7a2fc…` |

⇒ **同一个作品，两处显示的是两张不同的图**（用户可见的问题）。

⚠ T101 规格 §六 原写「扫描路径记的是**曲目封面**（`track_xxx`），专辑页用的是**专辑封面**（`album_xxx`），
实测两者**指向同一张图**」——**真机证明这句话是错的**（详见「二」）。

## 二、**唯一可行**的统一源（探针 `t102-01` 实测，2026-11-17）

真机探针（只读 GET，比对**四个**来源）：

| 来源 | 端点 | 实测 |
|---|---|---|
| 曲目**自己**的封面 | `/track/list` 的 `coverId` | 「庙堂之外」= `track_591e8c99…` |
| 曲目**内嵌专辑**的封面 | `/track/list` 的 `album.coverId` | 「庙堂之外」= `album_1988d5f2…` |
| **专辑自己**的封面 | `/album/detail?guid=` | 《让青春继续第一季》= `track_66f7a2fc…` |
| 专辑**第一首曲目**的封面 | `/track/album-detail/list?size=1` | 《让青春继续第一季》= `track_b9a2187d…` |

⇒ **三条结论**：

1. ⭐ **曲目的内嵌 `album.coverId` == `/album/detail` 的 `coverId`**（`track_66f7a2fc…` **三处逐字一致**）
   ⇒ **扫描路径零请求**就能拿到与专辑页 / 秒搜**完全相同**的那个 id；
2. ⭐ **曲目自己的封面与专辑封面是两个不同的 id** ⇒ 用曲目封面**永远统一不了**
   ⇒ 而且「取哪一首」在两条路里**定义不同**（扫描顺序 vs 专辑详情顺序）⇒ 曲目封面**不可能**统一；
3. ⇒ **统一源只能是「专辑自己的 `coverId`」**——它既是专辑页显示的那个，又是零请求拿得到的那个。

⚠ 附带发现：服务端**专辑**的封面**不一定是** `album_` 形态（315 条秒搜结果里 `album_` / `track_` / 空**都有**）
⇒ 「专辑页用 `album_xxx`、有声页用 `track_xxx`」这个说法**在服务端层面也不成立**。

### 三态（**关键**：`albumCoverId` 不能用真假值判断）

| 值 | 含义 | 页面行为 |
|---|---|---|
| `undefined`（**字段缺省**） | **未知**（T101 的旧落盘：只有曲目封面） | ⇒ 补拉一次 `/album/detail` |
| `null`（**字段是 null**） | **确认没有封面**（专辑确实没封面） | ⇒ **不**再拉（卡片画占位块） |
| 字符串 | 有封面 | ⇒ 直接显示 |

⚠ 「未知」与「确认没有」**必须**分开：混在一起 ⇒ 旧落盘永远不会被补拉 ⇒ 永远统一不了；
或「确认没有」的专辑每次进页面都重拉一次 ⇒ 白花请求。

⚠ **落盘里靠「字段在不在」区分**（`JSON.stringify` 会**丢掉**值为 `undefined` 的 key ⇒
读回来仍是「未知」⇒ 会再补拉 ⇒ 正是我们要的）。

## 四、验收点

1. **主列表**与**秒搜结果**里同名作品的卡片，封面 id **逐字相同**；
2. 该 id == **专辑页**那张专辑的封面 id（真机：`track_66f7a2fc…`）；
3. **旧落盘**（T101 形状：有曲目封面、无专辑封面）进页 ⇒ 补拉**一次** `/album/detail`
   ⇒ 卡片换成**专辑封面** ⇒ **回写落盘** ⇒ 下次**不再**拉；
4. 落盘里 `albumCoverId: null`（确认没有封面）⇒ **不**补拉 ⇒ 卡片是**占位块**
   （与秒搜结果**同样**是占位块 ⇒ 两边一致）；
5. `STATE_VERSION` **仍为 3** ⇒ 旧落盘可读 ⇒ **不逼用户重扫 52 秒**；
6. `tsc --noEmit` 0 error；Vitest 全绿；Playwright 全绿；**变异自证 ≥ 4 条全红 ⇒ 还原回绿**；
7. **真机复验**：主列表与秒搜的《让青春继续第一季》卡片 `coverSrc` **完全相同**。

### 三、⚠ 探针自己的坑（已修，记下来）

- ⚠ 封面 `<img>` 是**懒加载** ⇒ **在视口外**的卡片读不到 `src` ⇒ 只读**第一张**（它在视口内）；
- ⚠ 场景 A 的判据不能只等「有封面」⇒ 那会读到旧落盘里那个**曲目**封面
  ⇒ 改成「有封面 **且不是**曲目封面」；
- ⚠ 等扫描完成**不能**用「已加载 N / N」（老坑）⇒ 等状态行「上次扫描」**且**卡片数 > 0。
