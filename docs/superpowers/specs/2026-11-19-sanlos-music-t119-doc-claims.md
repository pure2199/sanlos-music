## 一、事实更正（**实测依据，不是推测**）

### 1. 旧结论是什么、错在哪

仓库里写着（6 处）：

> 服务端**不能浏览目录** / NAS 音乐服务**没有「浏览目录」的接口**（实测 20 个候选端点都不通）
> ⇒ 客户端只能**把曲库扫一遍**，再按目录名挑出这个文件夹里的作品。

⚠ **错的是「服务端不能」这个因**；**「客户端目前按目录名挑」这个果仍然为真**
（客户端**还没接**那些新接口）⇒ 修法不是改行为，是**改陈述**。

### 2. 新事实（**2026-11-19 真机实测**，FN 中继 `https://pure2199.fnos.net/music`）

飞牛音乐 **Web 前端由 NAS 自己托管** ⇒ 它的 JS 包里写着它**真正调用**的 API 路径
⇒ 扒主包 ＋ **44 个懒加载 chunk** ⇒ 反解出 **19 组 / 92 条**端点（路径＋方法）。

**新增的三族端点**：

| 端点组 | 端点（方法） |
|---|---|
| `folderView` | `/folder-view/list`（GET）、`/folder-view/playable-tracks`（POST）、`/folder-view/add-to-playlist`（POST）、`/folder-view/delete`（POST）、`/folder-view/recover`（POST） |
| `appCenter` | `/app-center/authed-dir/list`（GET）、`/app-center/authed-dir/sub/list`（GET）、`/app-center/authed-dir/sub/create`（POST） |
| `sharedLibrary` | `/shared-library/{list,detail,create,edit,delete,scan,scan-all,reconnect,reconnect-check}` |

> ⚠ **T133 订正（2026-11-21）**：上面这张表 `sharedLibrary` 一族的**最后一个端点写错了** ——
> 真实路径是 `/shared-library/reconnect/check`（**不是** `reconnect-check`）
> （2026-11-20 T122 真机反解飞牛前端确认 ⇒ 见
> `docs/superpowers/specs/2026-11-20-sanlos-music-t122-shared-library.md` §二.3）。
> ⚠ **原表那一行按纪律保留不动**（历史段不篡改）⇒ 订正写在这里，让看表的人**当场**看到。
> ⚠ 客户端**不接**这个端点（**全是 POST 写操作**；客户端是播放端 ⇒ 只读 `list` / `detail`）
> ⇒ **代码里没有这个错**（`src/api/sharedLibrary.ts` 写的就是真实路径）。

**真机实测**（只打 GET，**不碰任何写操作**）：

| 端点 | 实测 |
|---|---|
| `/album/list`（**对照**） | `code=0`，`total=34074` ⇒ 调用链路通 |
| `/folder-view/list` | `code=100002 invalid arguments`（**存在**，缺 `parentPath`）⇒ 带参 ⇒ `code=0` |
| `/app-center/authed-dir/list` | `code=0` ⇒ **2 个授权目录** |
| `/app-center/authed-dir/sub/list` | `?parent=` ⇒ `code=0` ⇒ 子目录树 |
| `/shared-library/list` | `code=0` ⇒ **2 个共享库** |
| `/artist/list-all` | `code=0` ⇒ `total=14875` |

**真实数据**：`/vol02/1000-0-3d135437` 下 **12 个子目录**
（03 DJ集合 / DJ打碟 / cover / 中国新歌声1-14期合集 / 中文音乐 / 日韩音乐 / **有声小说** /
欧美音乐 / 洛雪音乐 / 蒙面歌王歌曲合集 / **让青春继续** / 音乐多文件），
`/folder-view/list?parentPath=…` 直接给 `itemCount=173670` ＋ 每个子目录的曲目数。

⇒ **服务端现在能按目录浏览曲库了** ⇒ 旧结论**已过时**。

### 3. ⚠ 一个**必须记住**的坑（差点误判）

我**先猜**了 25 个 `/folder/*` 命名候选端点 ⇒ **全部不认**（响应体 `null`）⇒
差点得出「服务端没这功能」。真名是 **`/folder-view/*`**。

⇒ **判据**（下次探测服务端能力时照用）：

| 情况 | 响应 |
|---|---|
| 端点**不存在** | HTTP 200，body = **`null`** |
| 端点**存在但缺参** | `code=100002 invalid arguments` |
| 正常 | `code=0` |

⇒ **「猜的候选全是 null」≠「服务端没这能力」** ⇒ 必须先拿到**真实端点名**再下结论。
