# Sanlos Music v0.2.2 —— 发布说明

> 相对 **v0.2.1** 的一次更新：**外壳收尾** ——
> 去掉 **F12 调出开发者工具**，加上**版本号**与**项目地址**，
> 并让**自动更新默认从项目拉取**（不用先手填地址）。

发布日期：**2026-11-10**

---

## 一、这一版改了什么

### 1. 去掉 F12 调出开发者工具

- **F12 / Ctrl+Shift+I 都不再调出开发者工具**：按键被**显式吞掉**（拦下默认行为、什么都不做）。
- **打包后彻底开不出**：主窗口 / 经典悬浮窗 / 词岛 / 授权窗四个窗口一律关掉开发者工具
  ⇒ 任何途径都开不出来。
- ⚠️ **开发时仍可调试**：跑 `npm start`（未打包）时开发者工具照常可用 —— 只影响发给用户的成品。

### 2. 版本号（终于能一眼看到自己装的是哪一版）

- 「**设置 → 关于**」新增「**版本**」一行（与安装包属性同源）。
- 「**设置 → 更新**」顶部也显示当前版本。

### 3. 项目地址

- 「**设置 → 关于**」新增「**项目地址**」一行（源码仓库），**点开用系统默认浏览器打开**。

### 4. 自动更新：默认从项目拉取（不用先手填地址）

- **不填更新服务器地址也能检查更新** —— 主进程会自动回落到**项目自己的 Releases**。
- 更新源指向 `releases/latest/download` ⇒ **永远指向最新那版**，发新版不用改客户端代码。
- 设置页新增「**用项目地址**」一键填入；想换成自己的源也随时能改。
- 新增「**允许安装未签名的更新包**」开关（**默认关**）：
  - 本项目暂未办理代码签名证书 ⇒ 默认**只允许下载、不允许一键安装**（原行为一字未改）；
  - 勾上之后**只放宽「发布者身份」这一条** —— **SHA-512（启动前再验一次）与「同源」仍是硬闸**，
    哈希不符一律拒绝。**有风险**，请确认你信任这个下载源再开。

### 工程

- 单元测试 **2111** 条（+31）；Playwright E2E **32** 条（+3，真实 Electron）。
- **8 条变异自证全部被抓住**（含「把 F12 重新绑回开发者工具」—— e2e 立刻变红）。

## 三、怎么用

- **两种登录方式**：
  - **方式 A（推荐）**：填 **FN ID**，应用自动构造候选链路并并行探测，列出可达地址供你选；
  - **方式 B**：直接填 **NAS 地址 + 账号口令**（IP 只填 host 会自动补 `5666` / `5667`）。
- **没 NAS 也能用**：未登录时主区默认就是「本地音乐」页，可「添加文件 / 添加文件夹」
  导入本机音乐直接播；下载过的曲目也能直接播。
- ⚠️ **中继限速**：走中继链路（`https://<fnId>.fnos.net`）时播放会限速，
  客户端会带上 `mode=relay` Cookie —— 这是中继的**硬性关卡**，不带会返回 HTML 错误页。

## 四、安全边界（不可放宽）

- **渲染层永远拿不到凭证**：账号口令用 Windows **DPAPI**（`safeStorage`）加密后落盘；
  渲染层只能通过主进程的协议代理取数据，拿不到 token。
- **唯一出网通道**是应用自己的 **NAS 代理**；外部歌词源的抓取也全在主进程。
- **自动更新只查、只报**：不静默下载；下载后必须过 **SHA-512 校验**，
  且安装包地址必须**与更新清单同源**（清单不能把安装包指到别处）。
- **新开的「允许安装未签名更新包」只放宽「发布者身份」**：
  SHA-512 与同源仍是硬闸，签名者不符的包**不走**这条路。
- ⚠️ **本版仍未做代码签名** —— 见上文 SmartScreen 提示。
