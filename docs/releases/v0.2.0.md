# Sanlos Music v0.2.0 —— 发布说明

> 相对 **v0.1.0** 的一次大更新：**歌词**全面重做（真逐字卡拉OK、桌面歌词改酷狗样式、多源回退），
> 外加品牌 / 图标 / 托盘的外壳改动。

发布日期：**2026-11-09**

---

## 一、这一版改了什么

### 歌词（最大的一块）

- **真逐字卡拉OK**：接 **网易云 yrc**，逐字填色按**真实词级时间戳**推进，
  不再是按音节推算的（此前约 **73%** 的歌拿不到逐字字段）。
- **输出延迟补偿**：整份歌词按**音频输出延迟**整体延后，与**耳朵里真正听到的声音**对齐；
  **换输出设备立即生效**，不必切歌。
- **伪逐字按音节加权**：英文歌不再「几个词轮流整块变色」（长单词分到更长时间；中文行不变）。
- **识别 LRC 的 `[offset:±N]`**：此前被**整条丢弃**，现在同步校正标签。
- **逐字填充不再整行失效**：此前约 **7%** 的行因「词的字符数」与「行文本去空白后的字符数」
  两套口径对不上 ⇒ **整行退化成纯文本、完全不填色**；现已统一口径。
- **桌面歌词改成「酷狗桌面歌词」样式**（经典悬浮窗）：
  **只有歌词**（没有曲名 / 歌手 / 播放控制）、**背景完全透明**、**固定白字 + 深色描边**、
  **点击穿透**（不挡桌面）；**扫光固定亮蓝**（不再跟主题走 —— 换主题就换色的话，
  真机上整行都是主题蓝、白字几乎看不见）。
- **桌面浮窗与全屏歌词舞台「同一时刻同一行」**：浮窗**上面一行就是正在唱的那句**
  （按**行首时间戳**判定，与歌词舞台同源），**只有当前句扫光**，下一句不提前开扫。
- **灵动态词岛**：**没播放 / 暂停时不显示**（恢复播放自动回来）；左端换成**专辑封面**
  （没有封面时显示占位块，不留破图）。
- **歌词多源回退**：首选源不中 ⇒ 依次试 **网易云 → lrclib → QQ → 自定义模板**，
  每个源各自限时 3 秒；**命中哪个源就显示哪个源**，不装作是首选源。
- **切源 / 切优先级 / 改模板立刻生效**（桌面歌词与全屏歌词同步换）。
- **歌词优先级可切**：**线上优先**（缺省）/ **本地优先**（断网也有）。

### 外壳与品牌

- 应用名统一为 **Sanlos Music**：窗口标题、顶栏品牌、托盘、经典悬浮窗、动态词岛、
  关于页、安装包（**exe 文件名与 exe 产品名**）、以及 **fnOS 授权页上显示的应用名**。
- **自带应用图标**（零依赖生成）：托盘、任务栏按钮、打包产物的 exe / 安装包 / 快捷方式
  **统一**用同一枚图标；**托盘在播放中显示专辑封面**，闲置显示应用图标。

### 其它

- 曲库 / 播放 / 下载 / 本地音乐 / EQ / 回写等能力见仓库的
  [`docs/changelog.md`](https://github.com/pure2199/sanlos-music/blob/feature/fnmusic-desktop/docs/changelog.md)。

## 三、怎么用

- **两种登录方式**：
  - **方式 A（推荐）**：填 **FN ID**，应用自动构造候选链路并并行探测，列出可达地址供你选；
  - **方式 B**：直接填 **NAS 地址 + 账号口令**（IP 只填 host 会自动补 `5666` / `5667`，
    域名走标准端口 `80` / `443`）。
- **没 NAS 也能用**：未登录时主区默认就是「本地音乐」页，可「添加文件 / 添加文件夹」
  导入本机音乐直接播；下载过的曲目也能直接播。
- ⚠️ **中继限速**：走中继链路（`https://<fnId>.fnos.net`）时播放会限速，
  客户端会带上 `mode=relay` Cookie —— 这是中继的**硬性关卡**，不带会返回 HTML 错误页。

## 四、安全边界（不可放宽）

- **渲染层永远拿不到凭证**：账号口令用 Windows **DPAPI**（`safeStorage`）加密后落盘；
  渲染层只能通过主进程的协议代理取数据，拿不到 token。
- **唯一出网通道**是应用自己的 **NAS 代理**；外部歌词源的抓取也全在主进程。
- **自动更新只查、只报**：不静默下载；下载后必须过 **SHA-512 校验**，
  且安装包地址必须**与更新清单同源**（清单不能把安装包指到别处）。
- ⚠️ **本版仍未做代码签名** —— 见上文 SmartScreen 提示。
