# Sanlos Music v0.2.3 —— 发布说明

> 相对 **v0.2.2** 的一次更新：**歌词多了一个来源** ——
> 歌曲文件里**自带**的歌词也能用了，而且**真逐字会自动进卡拉OK**。

发布日期：**2026-11-10**

---

## 一、这一版改了什么

### 1. 音频内嵌歌词：歌曲文件里自带的歌词也能用了

主进程直接读音频文件的**内嵌标签**（**手写解析器，不引新依赖**）：

| 容器 | 读的标签 | 形态 |
|---|---|---|
| MP3 / AIFF | ID3v2 `USLT` | 行级（**整行显示，不假装逐字**） |
| MP3 / AIFF | ID3v2 `SYLT` | **真逐字** ⇒ 自动进卡拉OK |
| FLAC / Ogg | Vorbis 注释 `LYRICS` · `UNSYNCEDLYRICS` | 行级 |
| MP4 / M4A | `©lyr` | 行级 |
| WAV | RIFF 容器里的 `ID3 ` 块 | 同 MP3 |

- **真逐字才卡拉OK**：只有行级时间戳的歌词改成**当前行整行高亮**，**不假装逐字**。
- 渲染层的歌词解析器**一行没改**（主进程统一转成标准 LRC 文本再交出去）。

### 2. 覆盖三层

| 层 | 读的是什么 | 说明 |
|---|---|---|
| ① **本地导入**的歌 | 本机文件 | 标签最全 |
| ② **已下载**的 NAS 曲目 | **原文件** | 不是转码后的产物 |
| ③ **NAS 在线播放** | 只读**文件头 64 KB** | 读满即断开，**不把整首歌拉下来** |

### 3. 来源优先级链新增「音频内嵌」一层

- **线上优先** = **线上 → 内嵌 → NAS**；
- **本地优先** = **内嵌 → NAS → 线上**；
- **不用外部源时内嵌照用**（**不需要外网**）；
- 界面**如实显示**「歌词来源：音频内嵌」（**不装作是别的源**）；
- **不新增设置项** —— 设置里的「歌词来源」下拉**不加**内嵌（内嵌不是外部源）。

### 4. 修掉一个真缺陷：真逐字其实一直没生效

这一版之前，`SYLT` 帧里声明「**时间戳格式 = 2**」的文件会被**整帧放弃**。

- **ID3 规范**说 `2` = MPEG **帧号**；
- 但**现实中几乎所有** `SYLT`（尤其 Python 标签库 **mutagen** 写出的）都声明 `2`，
  **存的却是毫秒**（mutagen 自己的代码把约定写反了）；
- ⇒ **最常见的 `SYLT` 文件恰好全落在被放弃的那一档** ⇒ 「真逐字」在真机上**≈ 没有**。

现在：**格式 `1` 与 `2` 一律按毫秒读**；其它取值（`0` / `3+`）仍然**整帧放弃**（**不猜**）。

### 工程

- 单元测试 **2164** 条（+53）；Playwright E2E **34** 条（真实 Electron）。
- **10 条变异自证全部被抓住**（含「只读格式 1」「格式 0·3 也照读」两条新增的）。

## 三、怎么用

- **不用做任何设置**：装了就能用 —— 有内嵌歌词的歌，歌词会自动被读出来。
- **两种登录方式**：
  - **方式 A（推荐）**：填 **FN ID**，应用自动构造候选链路并并行探测，列出可达地址供你选；
  - **方式 B**：直接填 **NAS 地址 + 账号口令**（IP 只填 host 会自动补 `5666` / `5667`）。
- **没 NAS 也能用**：未登录时主区默认就是「本地音乐」页，可「添加文件 / 添加文件夹」
  导入本机音乐直接播；下载过的曲目也能直接播。
- ⚠️ **中继限速**：走中继链路（`https://<fnId>.fnos.net`）时播放会限速，
  客户端会带上 `mode=relay` Cookie —— 这是中继的**硬性关卡**，不带会返回 HTML 错误页。

## 四、已知影响（如实标注）

- ⚠️ **只对「文件里本来就带歌词标签」的歌曲生效**：NAS 服务端若统一转码
  （标准音质 = MP3 320k）⇒ **标签必丢** ⇒ 这一层对 **NAS 在线播放**可能始终读不到
  （**本地导入 / 已下载的原文件**不受影响）。
- ⚠️ **流式层只支持「元数据在文件头」的容器**（MP3 / FLAC / Ogg / WAV）：
  MP4 的 `moov` 常在文件尾 ⇒ 流式层**读不到** `©lyr`（**本地文件层**不受影响）。
- ⚠️ **少数真按 ID3 规范存 MPEG 帧号的 `SYLT`** ⇒ 我们会把它当毫秒 ⇒ 时间戳**偏早**、
  卡拉OK 走偏 —— **不会崩、不会显示错歌词**，只是时间不准。
  取舍：**「有歌词」优先于「时间绝对准确」**。
- ⚠️ **全屏歌词页多了一行来源说明**（以前只有线上源 / NAS 源会显示）。

## 五、安全边界（不可放宽）

- **渲染层永远拿不到凭证**：账号口令用 Windows **DPAPI**（`safeStorage`）加密后落盘；
  渲染层只能通过主进程的协议代理取数据，拿不到 token。
- **唯一出网通道**是应用自己的 **NAS 代理**；外部歌词源的抓取也全在主进程。
- **自动更新只查、只报**：不静默下载；下载后必须过 **SHA-512 校验**，
  且安装包地址必须**与更新清单同源**（清单不能把安装包指到别处）。
- ⚠️ **本版仍未做代码签名** —— 见上文 SmartScreen 提示。
