# Sanlos Music v0.2.1 —— 发布说明

> 相对 **v0.2.0** 的一次小更新：**只改歌词呈现** ——
> **真逐字才卡拉OK，否则整行显示**（不再按音节权重插值编造字级时间戳）。

发布日期：**2026-11-10**

---

## 一、这一版改了什么

### 歌词（唯一的一处改动）

- **真逐字才卡拉OK**：歌词行**带真逐字时间戳**（词源给的 `<mm:ss.xx>` 逐字标签）⇒
  卡拉OK 逐字填色**照旧**，一字未改。
- **只有行级时间戳 ⇒ 不再假装逐字**：此前按音节权重**插值编造**字级时间戳，
  扫光「动得很认真但就是不对」；现在**当前行整行**用强调色显示
  （**不渲染逐字着色层**，DOM 里零个逐字元素）。
- **判据落在数据源头**：逐行看词级时间戳是**源给的**还是**插值编造的** ——
  判据打在**造出假数据的那一层**，不在渲染层重新推断。
- **词岛 / 经典悬浮窗 / 全屏歌词舞台三处一致**。

### ⚠️ 已知影响

- **用 QQ 音乐源（只有行级 LRC）时，卡拉OK 扫光会消失**，改为「当前行整行强调色」。
  这是本改动的**本意**（不假装逐字）；想看到扫光，需要换到**能给真逐字**的词源
  （实测网易云 yrc 覆盖约 **27%** 的歌，且大牌歌常常没有）。

### 工程

- 单元测试 **2080** 条（+24）；Playwright E2E **29** 条（+2，真实 Electron）。
- 5 条**变异自证**全部被抓住：判定反了 / IPC 不透传 / CSS 硬编码 /
  伪逐字也渲染着色层 / 整行判据漏条件。

## 三、怎么用

- **两种登录方式**：
  - **方式 A（推荐）**：填 **FN ID**，应用自动构造候选链路并并行探测，列出可达地址供你选；
  - **方式 B**：直接填 **NAS 地址 + 账号口令**（IP 只填 host 会自动补 `5666` / `5667`）。
- **没 NAS 也能用**：未登录时主区默认就是「本地音乐」页，可「添加文件 / 添加文件夹」
  导入本机音乐直接播；下载过的曲目也能直接播。
- ⚠️ **中继限速**：走中继链路（`https://<fnId>.fnos.net`）时播放会限速，
  客户端会带上 `mode=relay` Cookie —— 这是中继的**硬性关卡**，不带会返回 HTML 错误页。

## 四、安全边界（不可放宽）

- **渲染层永远拿不到凭证**：账号口令用 Windows **DPAPI**（`safeStorage`）加密后落盘；
  渲染层只能通过主进程的协议代理取数据，拿不到 token。
- **唯一出网通道**是应用自己的 **NAS 代理**；外部歌词源的抓取也全在主进程。
- **自动更新只查、只报**：不静默下载；下载后必须过 **SHA-512 校验**，
  且安装包地址必须**与更新清单同源**（清单不能把安装包指到别处）。
- ⚠️ **本版仍未做代码签名** —— 见上文 SmartScreen 提示。
